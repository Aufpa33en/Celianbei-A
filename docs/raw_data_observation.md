# A题原始数据观察与图示说明

## 原始数据提供的信息

原始附件由电池级摘要表与循环级时序表构成，可研究四类关系：

1. **充电策略与退化响应**：`C1`、`Q1`、`C2`及`policy`与`SOH`、`capacity`随循环次数的变化关系。
2. **充电效率与寿命权衡**：`chargetime`或`mean_chargetime`与SOH衰减速度之间的关系。
3. **运行状态与健康状态**：循环级`IR`、`Tavg`与`SOH`、`capacity`的同步变化关系。
4. **预测边界**：`prediction_test=1`的9块电池仅观测到150循环，其余40块观测到200循环，可用于问题3的截断验证和未来预测。

图`fig01b_normal_soh_by_policy`主要展示“充电策略—循环次数—原始SOH”的关系，并在每种策略内部保留电池间差异。图`fig01a_battery1_cycle12_anomaly`展示异常循环中容量、SOH、附件平滑SOH、内阻、温度和充电时间的同步变化。

## 电池1第12循环尖峰

该尖峰不是绘图程序产生的，原始`cycle_train.csv`中对应记录为：

- `battery_id=1`，`cycle=12`；
- `capacity=1.5390544 Ah`，相对循环10、11、13、14容量中位数约增加43.2%；
- `SOH=1.4374427`，由异常容量直接传导；
- `IR=0.018950272`，是循环表中的最大内阻；
- `Tavg=30.282579`，相对邻近循环同步下降；
- `chargetime=13.341273`，未出现同量级跳变；
- 附件的`SOH_smooth`在循环10—14被抬高至约1.09，已受尖峰影响。

真实电池容量不太可能在一个循环内增加43.2%并在下一循环恢复，因此该记录更符合多变量测量、采集或拼接异常，而非真实寿命改善。现阶段只将其列为“待清洗异常候选”，未从原始数据中删除或替换。正式清洗时应制定统一、可复现的异常判定和修复规则，再做敏感性比较。

## 其他需要后续审核的原始现象

- 电池41从第1循环起SOH约为0.954，属于整体基线偏低，而非单点尖峰；需要核对初始容量定义或批次差异，不能按电池1的规则直接删除。
- 电池2和电池3在第12循环的`IR=0`，不符合正内阻的物理含义，属于待审核缺失编码候选。
- 策略`80PER_3_6C`对应3块电池的`C1`为空。该策略可能表示直接采用第二阶段3.6C充至80% SOC，也可能是字段缺失；需要结合公开数据集策略定义决定编码方式。
- 循环表无缺失单元格和完全重复行；摘要表仅上述3个`C1`为空。

## 图件使用说明

- `fig01a_battery1_cycle12_anomaly`：用于论文的数据质量诊断或清洗依据部分。
- `fig01b_normal_soh_by_policy`：用于论文的数据概览与策略差异初步观察部分。
- “正常尺度”仅指绘图坐标未被电池1尖峰压缩，不表示图中其余所有记录已经通过清洗。
