# A题数学模型候选框架

## 总体原则

样本只有49块电池，且每种策略仅3—8块。主模型应优先选择结构清楚、参数可解释、能按电池进行验证的方法；复杂机器学习模型只适合作为比较模型。模型输入采用清洗后的循环数据，异常标记仅用于审计和敏感性分析。

## 问题1：健康状态变化规律

### 候选模型

1. **广义加性混合模型（GAMM）**
   \[
   SOH_{i,t}=f(t)+f_{p(i)}(t)+b_i+\varepsilon_{i,t},
   \]
   其中`f(t)`描述总体非线性退化，`f_p(t)`描述不同充电策略的偏离，`b_i`表示电池个体差异。
2. **函数型数据分析**：把每块电池的SOH视为一条函数曲线，比较策略间平均曲线、导数和曲线距离。
3. **分段线性或二次退化模型**：作为容易解释的基线模型，比较早期斜率和曲率。

### 暂定推荐

以GAMM为主模型，函数型曲线比较和分段回归作为辅助。它能同时处理重复测量、非线性趋势和同策略电池差异。

## 问题2：策略参数影响与显著性

### 候选模型

1. **线性混合效应模型**：以循环数、`C1`、`Q1`、`C2`及交互项为固定效应，以电池为随机效应。
2. **广义加性混合模型**：当充电参数作用明显非线性时，用平滑函数代替线性项。
3. **置换检验或参数自助法**：在小样本和不均衡重复数下，为显著性结论提供更稳健的置信区间。

### 暂定推荐

先做参数共线性与样本覆盖检查，再以简化的混合效应模型为主；若残差显示非线性，再升级为GAMM。`80PER_3_6C`的`C1`缺失不猜补，该策略保留在类别比较中，但不进入`C1`连续效应估计。

## 问题3：第151—200循环与寿命预测

### 候选模型

1. **分层非线性退化模型**：指数、幂律或二次模型，策略决定总体参数，电池具有随机参数。
2. **高斯过程回归**：直接给出SOH预测区间，适合平滑的小样本序列，但远期外推依赖核函数。
3. **状态空间模型或卡尔曼滤波**：将真实健康状态与测量噪声分离，适合滚动更新。
4. **Elastic Net早期特征模型**：用前150循环斜率、曲率、内阻、温度、充电时间等特征预测后50循环指标，作为机器学习基线。

### 暂定推荐

以“分层非线性退化模型”为主，以高斯过程和Elastic Net为对照。用40块完整电池模拟截断至150循环，按电池交叉验证第151—200循环；80% SOH寿命只报告外推区间，不宣称已被真实寿命数据验证。

## 问题4：充电时间与寿命的多目标优化

### 候选模型

1. **代理模型加Pareto优化**：用问题2、3建立的模型预测寿命和充电时间，再计算非支配策略集合。
2. **加权综合评价**：对寿命、充电时间和不确定性归一化后求加权得分，用于给出特定偏好的单一推荐。
3. **NSGA-II**：当允许在连续参数空间内搜索新策略时使用，但必须限制在已观测参数范围附近，避免无依据的远距离外推。

### 暂定推荐

论文主结果采用Pareto前沿，不预先替用户指定唯一权重；再给出偏寿命、均衡、偏速度三种情景推荐。NSGA-II仅在代理模型通过留一策略验证后采用。

## 建议的建模顺序

1. 先完成问题1的描述统计、曲线特征和GAMM，确认不同策略退化形态。
2. 问题2用混合效应模型分离策略参数效应与电池个体差异。
3. 问题3比较三类预测模型，并用统一的电池级回测指标选择主模型。
4. 问题4复用前述模型作为代理函数，求Pareto前沿并开展不确定性分析。
