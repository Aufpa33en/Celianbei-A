# 第四问模型方向与边界

## 1. 题目范围

第四问要求基于前两问设计兼顾充电时间与寿命衰减的两阶段快充策略优化。策略由第一阶段倍率`C1`、切换SOC`Q1`和第二阶段倍率`C2`描述，并要求优先在已有实验策略范围内比较。

第四问适用既定阶段方法，但不是简单重复第三问：它继承第二问的策略级退化响应和SOC暴露描述，同时新增时间目标、Pareto比较和策略推荐；第三问只作为已观测策略的SOH轨迹/不确定性辅助，不直接承担新策略反事实生成。

## 2. Review意见采纳

### 采纳

1. 采用9个已有策略的离散Pareto优化作为主模型，时间主指标统一使用电池摘要表中实测`mean_chargetime`的策略内均值，前200循环逐循环均值只作敏感性分析；衰减使用预先固定的200循环SOH损失/末段衰减指标。
2. 对策略电池进行整块bootstrap，报告时间、衰减和Pareto保留状态的不确定性。
3. 时间与SOH损失不直接相加；主决策使用Pareto前沿、给定衰减容忍度下的最短时间和膝点，权重扫描仅作敏感性。
4. 受限连续响应面只使用低维暴露量`J`或`H`，并限制在已有参数坐标凸包/合理邻域内；执行留一策略验证和策略级bootstrap。
5. 显式记录`T0`近似恒定、实际充电时间受结构/批次/温度/内阻影响，不能把理论`T0`当作可识别的实测时间效应。
6. 明确`80%`终点没有真实标签，Q3的T80只能作为情景外推，不作为Q4的已验证寿命目标。

### 不采纳

1. 不把Q3 `C_ridge`直接作为任意`(C1,Q1,C2)`的反事实寿命模型。新策略没有真实早期轨迹，不能可靠构造Q3动态特征。
2. 不拟合完整三参数主效应、二次项和交互项。完整参数坐标只有约7个，且存在旧/新结构混杂、`J`与`H`高相关和`C1`缺失策略。
3. 不使用联合层次时间—寿命模型作为主模型。策略层样本少，时间和退化的结构/批次混杂无法稳定分离。
4. 不在观测凸包外自由搜索高倍率或新SOC切换点；任何连续结果只能标为探索性。

## 3. 拟比较模型

### M0：离散经验Pareto主模型

对策略`p=1,...,9`定义

\[
T_p=\operatorname{mean}_{i\in p}(\operatorname{mean\_chargetime}_i),
\qquad
D_p=1-\operatorname{SOH}_{i,200}/b_i
\]

或使用预先规定的末段衰减率作为敏感性响应。`T_p`和`D_p`分别在策略内整块bootstrap得到不确定区间。若不存在另一个策略`r`使`T_r\le T_p,D_r\le D_p`且至少一项严格更优，则`p`保留在Pareto前沿。

在前沿上报告两种推荐规则：

- 给定退化容忍度`D_max`时选择最短时间策略；
- 对min-max标准化后的时间和退化取权重扫描，报告膝点和推荐稳定区间。

### M1：受限低维响应面敏感性

仅在完整参数策略坐标上拟合

\[
D_p=\beta_0+\beta_J\widetilde J_p+\epsilon_p
\]

或在预先登记的比较中替换为单一`H`。由于`corr(J,H)\approx0.87`且Q2选择校正后未支持独立参数效应，`J+H`只作为敏感性，不作为主模型。时间模型优先使用实际策略时间；理论恒流时间

\[
T_{0p}=60\left(\frac{q_p}{C_{1p}}+\frac{0.8-q_p}{C_{2p}}\right)
\]

只作为解释量，不能替代实测时间。连续优化域限制在已有完整坐标的凸包（含边界）和每个分量的观测范围内，且必须输出距离最近观测点、`in_hull/extrapolation`状态。每个留一坐标训练折独立计算标准化均值/尺度、岭参数和拟合结果；两个相同`(4.8,0.8,4.8)`坐标必须一起留出，缺失`C1`策略不进入M1。

### M2：不采用的联合模型

联合时间—衰减层次模型、自由三参数响应面、Q3条件预测器加连续策略输入均不进入主结果。它们要么不可识别，要么把条件预测误当成反事实寿命。

## 4. 评价和停止规则

- 所有主指标在40块完整电池上计算，9块`prediction_test=1`电池不参与Q4调参或优化。
- 时间和退化先分别报告，再进行Pareto/约束选择；任何综合分数都必须说明它是决策偏好而非统计估计。
- M1若留一策略误差、系数符号或bootstrap排名不稳定，则停止连续优化，正式答案退回M0离散Pareto。
- 若M1在至少4/7个留一坐标折中未优于常数基线，或其bootstrap中同一推荐的选择频率低于0.60，则停止连续优化，正式答案退回M0；若M0的Pareto前沿在5000次bootstrap中没有任何策略保持频率达到0.60，则只报告前沿集合，不强行推荐单一折中方案。凸包外候选永远只能作为探索性结果。
- Q4 smoke只用于排错、运行时间和模型可识别性检查；未经阶段报告和用户放行，不运行全量bootstrap/敏感性最终版本。

## 5. 预估运行时间

- M0离散Pareto、策略级2000—5000次bootstrap：约1—3分钟。
- M1留一策略验证、低维网格和bootstrap：约1—5分钟。
- 合并数据审计、敏感性表和报告：约1—3分钟。
- 若进入严格嵌套重采样，预计总计约5—15分钟；联合层次模型可能更久且不稳定。

## 6. 论文边界

推荐策略只能表述为“在本数据集9个已观测策略范围内的时间—退化折中推荐”。不能宣称`C1、Q1、C2`的独立因果最优值，也不能把推荐策略外推到未观测倍率、SOC区间或新电芯结构。
