# A题数据清洗候选策略

## 1. 清洗目标与边界

本题只有49块电池，每种策略包含3—8块电池。整块删除会削弱策略间比较和问题3的训练样本，因此清洗应优先修复可定位的单点错误，并保留真实的电池个体差异。

清洗程序必须同时保留三份数据：官方原始数据、带异常标记的审计数据和用于建模的清洗数据。论文中的原始数据图使用官方数据；统计模型和预测模型使用清洗数据，并用原始数据或不同清洗版本做敏感性检验。

## 2. 当前数据给出的清洗依据

### 2.1 结构与公式一致性

- `battery_summary.csv`包含49个唯一电池编号；`cycle_train.csv`包含9350条唯一的“电池—循环”记录。
- 循环表没有空单元格和完全重复行。
- 40块训练电池各有200个循环，9块测试电池各有150个循环。
- 全部记录严格满足
  \[
  SOH_{i,t}=\frac{Capacity_{i,t}}{InitialCapacity_i},
  \]
  最大计算残差为`5.55e-16`。因此容量异常会直接传导到SOH，不能把二者当作两个独立异常。

### 2.2 已定位问题

1. **电池1第12循环的孤立尖峰**  
   容量为1.5390544 Ah，较循环10、11、13、14的容量中位数高43.2%；SOH为1.4374427。该点的局部稳健标准分数超过1200。采用“局部稳健标准分数大于8且偏离局部中位数超过2%”的联合规则时，全表只标记这一条容量记录。内阻和温度在同一循环也出现同步异常。
2. **电池2、3第12循环的内阻为0**  
   电池内阻应为正值；这两条记录更符合缺失值编码，而不是有效测量。
3. **电池41的整体低SOH基线**  
   电池41前5循环SOH中位数为0.95284；49块电池对应中位数为0.99760，电池41的稳健标准分数为-48.39。该电池从第1循环起整体偏低，不属于孤立尖峰。
4. **策略`80PER_3_6C`的`C1`缺失**  
   该策略包含3块电池，摘要表中的`C1`均为空。仅凭文件名不能确定这是“不适用”还是遗漏值。
5. **附件平滑序列受尖峰污染**  
   电池1的`SOH_smooth`在第10—14循环被抬至约1.09。后续模型不应直接把附件平滑列当作无异常真值。

## 3. 候选清洗策略

### 策略A：最小干预，只处理硬错误

处理规则：

1. 检查主键、循环连续性、重复行、变量类型和公式一致性。
2. 将`IR<=0`改记为缺失值；若前后循环都有有效值，使用相邻两点线性插值。
3. 用以下联合规则识别孤立容量异常：
   \[
   z^{loc}_{i,t}=\frac{|Q_{i,t}-\operatorname{med}(N_{i,t})|}
   {1.4826\operatorname{MAD}(N_{i,t})},
   \]
   其中`N`取同一电池前后各2个循环，不包含当前点。当`z_loc>8`且相对局部中位数偏差超过2%时标记异常。
4. 对孤立异常点使用前后相邻有效点线性插值；根据初始容量重新计算SOH。
5. 保留电池41，不修改其初始容量；保留`C1`缺失状态。

理由：该策略只修改具有物理矛盾或强局部证据的记录。联合阈值在当前数据上只识别电池1第12循环，误伤正常缓慢退化的风险较小。

局限：电池41的基线差异仍会影响绝对SOH比较；策略参数模型不能直接使用`80PER_3_6C`的`C1`。

### 策略B：局部稳健修复，并重新生成趋势序列

处理规则：

1. 先执行策略A的结构检查和硬错误修复。
2. 不再使用附件中的`SOH_smooth`作为建模输入。
3. 基于修复后的原始SOH，按每块电池分别计算稳健局部回归曲线，例如MATLAB的`rlowess`，窗口取11个循环。
4. 用7、11、15三个窗口重复分析；只有在主要排序和结论一致时，才采用11点窗口作为论文主结果。
5. 不施加强制单调约束。数据前期存在容量激活和测量波动，单调回归可能把真实的早期变化误判为噪声。

理由：电池1证明附件平滑列会被极端点污染。稳健局部回归能降低孤立异常对趋势的影响，同时保留非线性退化形状。窗口敏感性检验可避免人为选择某个平滑参数。

局限：平滑曲线适合趋势、斜率和预测特征提取，不能替代原始测量值。问题3模拟“仅观测前150循环”时，必须只使用该截断样本重新平滑，禁止使用151—200循环信息。

### 策略C：基线校正的双轨分析

处理规则：

1. 保留题目定义的绝对SOH作为主指标。
2. 另计算相对退化指标：
   \[
   SOH^{rel}_{i,t}=\frac{Capacity_{i,t}}
   {\operatorname{median}(Capacity_{i,1:5})}.
   \]
3. 策略比较同时报告绝对SOH、相对SOH和相对首5循环的SOH变化量。
4. 在回归或混合效应模型中加入电池随机截距或初始SOH协变量。

理由：电池41的低值来自整条曲线的初始基线，而非中途突降。基线校正可以把“初始状态差异”和“循环退化速度”分开。保留绝对SOH可维持题目定义，避免用重新归一化掩盖初始健康差异。

局限：`SOH_rel`不是题目规定的SOH，只能作为辅助指标和敏感性分析，不能替换寿命终止阈值中的80% SOH。

### 策略D：异常电池整体剔除

处理规则：从建模样本中删除电池1、电池41或其他达到电池级阈值的样本，再拟合模型。

理由：该策略可检验少数异常电池是否主导结果。

不建议作为主方案：本题样本量小，部分策略只有3块电池。删除电池1后`3_6C-80PER_3_6C`只剩2块；删除电池41后其策略只剩5块。整体剔除会损失大量正常循环，并可能人为缩小电池间差异。该策略只适合作为稳健性对照。

## 4. 推荐主方案

论文主分析建议采用“策略A + 策略B + 策略C辅助分析”的分层方案：

1. **保留官方原始数据**，任何脚本都不得覆盖`data/raw/`。
2. **修复硬错误**：修复电池1第12循环容量及SOH；将电池2、3第12循环零内阻改为缺失并局部插值。
3. **重新生成稳健趋势**：在修复后的SOH上使用11点`rlowess`，并用7点和15点窗口检验结论稳定性。
4. **保留电池41**：绝对SOH模型加入初始状态或随机截距，同时用`SOH_rel`比较退化速度。
5. **不猜补C1**：问题1按`policy`分类比较；问题2分析`C1`时将`80PER_3_6C`排除出该参数的连续效应估计，但保留在策略类别比较中。只有查到公开数据集的策略定义后才能补充编码。
6. **不强制单调、不整块删电池**：用敏感性分析评估电池1、电池41对结论的影响。

该方案区分了四类情况：孤立异常点、物理无效值、整体基线差异和未知策略参数。每类问题使用不同处理方法，避免用统一阈值删除有意义的电池差异。

## 5. 论文可采用的清洗说明

> 我们首先检查电池编号、循环编号、重复记录、缺失值及SOH计算一致性。循环表中9350条记录均满足SOH等于当前容量与初始容量之比。针对时序单点异常，我们在每块电池内部使用前后各2个循环构成局部邻域，并采用局部MAD标准分数与相对偏差联合判据；当局部稳健标准分数大于8且相对偏差超过2%时，将该点标记为异常。该规则在全数据中仅识别出电池1第12循环，其容量较邻近中位数高43.2%，并伴随内阻与温度同步异常。我们采用相邻有效循环线性插值修复容量，随后按初始容量重新计算SOH。对于电池2、3第12循环的零内阻，考虑到电池内阻应为正值，将其视为缺失记录并用相邻循环插值。附件提供的SOH平滑序列受到异常尖峰影响，因此我们在修复后的SOH上重新采用11点稳健局部回归提取退化趋势，并用7点和15点窗口开展敏感性检验。电池41从首循环开始表现出整体低SOH基线，我们保留该电池，在模型中控制初始状态，并增加相对首5循环容量的归一化退化指标作为辅助分析。对于`C1`缺失的`80PER_3_6C`策略，我们保留其策略类别，但不将未知`C1`用于连续参数效应估计。
