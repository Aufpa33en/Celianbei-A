# A题模型验证边界与方案

## 可直接验证的部分

40块非测试电池提供第1—200循环数据。问题3建模时，将每块完整电池人为截断至第150循环，只允许模型读取第1—150循环，并以真实的第151—200循环作为隐藏测试区间。验证必须按电池划分训练集和验证集，不能把同一电池的不同时刻同时放入训练和验证数据。

建议采用两层回测：

1. **留一电池或分组交叉验证**：每次留出一块完整电池，使用其余电池拟合模型，再预测被留出电池的第151—200循环。
2. **留一策略验证**：在样本数允许时，留出某一充电策略的全部完整电池，检验模型对未见策略或相邻策略的泛化能力。若策略参数空间过稀，应将该结果标为外推测试。

评价指标至少包括第151—200循环RMSE、MAE、最大绝对误差、末循环SOH误差和预测区间覆盖率。9块`prediction_test=1`电池的第151—200循环真值没有公开，本地不能计算其最终误差。

## 不能直接验证的部分

当前数据最低SOH约为0.95，没有电池达到题目规定的80%寿命终止阈值。因此数据无法直接验证80% SOH对应的真实循环寿命。模型只能通过以下证据约束外推风险：

- 第151—200循环滚动回测；
- 使用100、120、150等不同早期观测长度比较预测稳定性；
- 比较多种退化模型的外推结果；
- 报告参数不确定性和寿命预测区间；
- 对平滑窗口、异常处理、电池41是否纳入等选择做敏感性分析。

论文不得把短期回测误差等同于80%寿命预测已经得到真实验证。最终寿命结果应表述为“基于早期退化规律的外推估计”。
