# 第一问四个小问文字回答

## 结论边界

按出题组回复，问题1中的“循环寿命”定义为SOH下降至80%时的循环数。附件只给出早期循环且没有电池实际达到80% SOH，因此寿命必须由早期SOH趋势外推，不能把CSV中没有寿命字段解释为数据缺失。为保证49块电池可比，本文统一只使用各电池前150循环：用40块具有151—200循环真值的电池选择末段趋势窗口，再对全部49块电池估计T80。SOH150、SOH200、前期损失和衰减率只作辅助分析。

## 1. 不同电池的策略、SOH曲线、循环寿命与充电时间

寿命主模型在每块电池前150循环内拟合末段局部线性趋势，并求其与SOH=0.8的交点。30、40、50、60、80循环窗口通过“仅看前150循环、预测已知151—200循环”的回测比较，40循环窗口的策略等权RMSE最低，为0.000706；平均电池RMSE为0.000316，最坏电池RMSE为0.002271。

## 2. 不同快充策略的寿命分布

策略寿命分布以电池级T80为基本样本，策略中位数为主统计量；2000次策略内整块电池bootstrap用于区间和排名概率。36组策略对的电池级T80精确置换检验经Holm校正后仍为0组显著。原因包括每策略只有3—8块电池、检验分辨率有限，以及T80本身含有外推误差。该结果不能解释为九种策略寿命等价。

窗口敏感性下，旧结构4.8C和3.7C-31%-5.9C始终位于末端；中上游策略的T80数值和局部次序会随窗口变化。因而“明显短寿命策略”比“长寿命策略内部的精确名次”更稳定。

## 3. 典型长寿命与短寿命策略

按T80点排名，典型长寿命候选为3.6C-80%-3.6C、4.8C-80%-4.8C（新结构）和5C-67%-4C（新结构）。其中新结构4.8C进入Top 3的bootstrap概率为93.0%，证据最稳定；3.6C和5C策略分别为75.75%和68.85%，应保留排名不确定性。

典型短寿命候选为80%-3.6C、旧结构4.8C和3.7C-31%-5.9C（新结构）。旧结构4.8C和3.7C策略进入Bottom 3的概率均为100%，短寿命特征稳定；80%-3.6C只有60.35%，不宜作同等强度结论。

## 4. 长短寿命策略差异及解释

短寿命最稳定的3.7C-31%-5.9C策略在31% SOC后升至5.9C，使电池在31%—80% SOC的大范围内承受高倍率；旧结构4.8C则在主要快充区间持续4.8C。长寿命候选中的5C-67%-4C在67% SOC后降至4C；4.8C新结构虽具有相同名义充电参数，却明显优于旧结构，说明结构/批次信息不能被C1、Q1、C2完全替代。

结果仍不支持“充电越慢，寿命一定越长”。5C-67%-4C平均充电约10.16 min，但预测寿命中位数高于充电约14.28 min的80%-3.6C。更合理的解释是中高SOC倍率暴露、结构/批次和个体退化差异共同影响寿命。由于策略不是随机分配，以上是关联解释，不是独立因果效应。
