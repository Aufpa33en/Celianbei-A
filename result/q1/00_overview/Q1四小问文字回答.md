# 第一问四个小问的文字回答

## 结论边界

题目用 SOH 降至 80% 定义循环寿命，但当前数据没有记录到该终点。40 块电池观测至第 200 循环，9 块测试电池观测至第 150 循环，全部已观测 SOH 均高于 80%。本文用第 200 循环 SOH 和前 200 循环 SOH 损失描述寿命表现，不把局部线性外推的 80% 寿命视为真实寿命。

## 1. 不同电池的快充策略、SOH 曲线、寿命表现和充电时间

数据包含 49 块电池和 9 种快充策略。每块电池均记录循环次数、容量、SOH、充电时间、内阻、平均温度及对应策略。清洗后的 SOH 曲线在前 200 循环内缓慢下降，电池间仍存在初始状态和退化速度差异。

主模型采用两阶段函数型曲线：先对每块电池的 SOH 曲线拟合三次样条，再在策略内等权平均电池系数。扩展超参数网格后，三折验证选中无惩罚端点 `lambda_curve=0`，因此不再把最终解称为岭回归。泛化误差使用外层留一电池验证，每个外层折内只用其余电池重新选超参和模型家族；40折均选中函数型家族，完整选择流水线 RMSE 为 0.004325。三种最终拟合模型给出的周期 200 策略排序一致。

## 2. 不同快充策略下的寿命分布

9 种策略的第 200 循环 SOH 点估计分布在 96.591% 至 99.668% 之间，极差约为 3.08 个百分点。三种候选模型的策略排名完全一致，说明总体排序不依赖单一曲线形式。

本文以整块电池作为统计单位。2000 次策略内聚类 bootstrap 用于置信区间和排名稳定性；两两显著性改用合并样本的双侧精确置换检验，再按指标执行 Holm 校正。36 组策略对的 SOH200 比较中，校正后显著的策略对为 0 组；同时有 20 组未作多重比较校正的电池 bootstrap 95% 区间不跨 0。后者不是同时置信区间，不能改报为 20 组确证差异；精确置换在每策略仅 2—7 块完整电池时分辨率又很粗。因此必须并列报告两种不确定性摘要；0 组 Holm 确证差异不代表九种策略等价。第二问另以末段退化速率进行单次全局置换检验，用于回答“至少一个策略是否不同”，不与本处的 SOH200 两两检验混用。

## 3. 典型长寿命策略与短寿命策略

按照第 200 循环 SOH 点估计，典型长寿命策略为：

- 3.6C-80%-3.6C；
- 5C-67%-4C（新结构）；
- 5.3C-54%-4C（新结构）。

三者进入 Top 3 的自助概率分别为 91.40%、85.75% 和 77.20%。前两种策略达到 80% 稳定性标准，第三种策略的排名仍有不确定性。

典型短寿命策略为：

- 3.7C-31%-5.9C（新结构）；
- 80%-3.6C；
- 4.8C-80%-4.8C。

三者进入 Bottom 3 的自助概率分别为 100%、81.45% 和 71.00%。其中，3.7C-31%-5.9C 的短寿命特征最稳定。

4.8C-80%-4.8C（新结构）受电池 41 初始 SOH 基线影响较大。改用相对 SOH 或排除电池 41 后，该策略排名上升，因此不能把所有 4.8C 策略归入短寿命组。

## 4. 典型长寿命与短寿命策略的差异及解释

典型长寿命策略限制了中高 SOC 区间的充电倍率。5C-67%-4C 在 67% SOC 后把倍率降至 4C；5.3C-54%-4C 在 54% SOC 后降至 4C；3.6C-80%-3.6C 则在主要快充区间保持较温和的 3.6C。

3.7C-31%-5.9C 在 31% SOC 时切换至 5.9C，使电池在 31% 至 80% SOC 的较宽区间承受高倍率。该策略的平均充电时间为 10.852 min，但第 200 循环 SOH 只有 96.587%。持续的中高 SOC 高倍率可能增强电化学极化和欧姆发热，并增加活性锂损失、界面副反应及析锂风险。

结果没有显示“充电时间越长，寿命表现越好”的单调关系。5C-67%-4C 和 5.3C-54%-4C 的平均充电时间约为 10.16 min，同时保持较高的第 200 循环 SOH。高倍率出现的 SOC 区间及持续范围比单一倍率大小更能解释现有策略差异。

上述机制解释来自现有数据中的关联和电化学研究，不能作为独立随机实验下的因果结论。结论适用于题目给出的 LFP/石墨电池、前 200 循环和已观测策略范围。
