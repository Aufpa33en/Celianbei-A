- `01_smoke_test/`：首次字段契约排错后生成的旧smoke快照，不作为当前权威结果。
- `01_smoke_test_v2/`：修正输入字段契约、加入模型比较和M1停止指标后的当前smoke权威目录。
- `02_full_validation_v1/`：第一次全量计算的审查快照；因缺少约束bootstrap、统一末段斜率区间和双时间口径审计，不作为论文权威结果。
- `02_full_validation/`：Q4正式权威结果（`q4_full_v4`）；充电时间主指标与Q1/Q2统一为逐电池`mean_chargetime`，前200循环均值仅作敏感性；另包含5000次整块电池bootstrap、11点权重扫描、约束推荐频率、快速候选成对比较、`T0`、末段衰减和当前单J岭代理失败证据。

论文主报告位于`reports/q4_full_validation_report.md`。正式快速折中结论是5.3C与5.0C两个候选的集合，不是唯一赢家；仅适用于9个已有实验策略，不外推到新倍率、新SOC切换点或新结构。
