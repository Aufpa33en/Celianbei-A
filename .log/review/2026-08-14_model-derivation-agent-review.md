# A题模型推导独立复核记录

- 日期：2026-08-14
- 范围：`docs/mathematical_models_from_literature_A.md`
- 方式：完成初稿后，分别由三个子agent独立检查模型一/二、模型三/四和模型五；主agent复算数据条件数并逐项决定是否采纳。

## 已确认正确的推导

1. 函数型混合效应模型的边际协方差与给定方差参数后的GLS估计正确。
2. 两阶段充电理想时间 `T0`、总电流应力代理 `J`、高SOC加权应力 `H` 的积分正确，适用条件为 `C1,C2>0`、`0<=q<=0.8`、0% SOC起充、两段恒流且忽略恒压尾段。
3. 约束二次退化模型的导数为负，80% SOH交点的非负根及 `k -> 0` 极限正确。
4. 高斯过程条件均值正确；原式(25)实际对应潜在轨迹协方差。
5. 增强切比雪夫标量化在正权重下产生Pareto有效解的反证思路正确。

## 已采纳的修正

1. 不同固定效应模型的策略似然比检验改用ML重拟合；REML只用于最终参数估计。全局检验使用零假设参数自助法，效应区间使用策略内电池级聚类自助法。
2. 模型二补充电池内AR(1)残差；条件数明确区分未标准化和标准化口径。主agent复算得到标准化条件数：`(C1,q,C2)=1.978`、`(T0,J,H)=19.885`、`(J,H)=3.791`。
3. 明确8个完整策略标签只有7个唯一参数坐标；结构变量只能表示结构/数据集/批次联合关联。
4. 策略寿命改为抽取随机效应后得到分布；修正 `a<=0.8` 的左删失解释。
5. GP删除与随机退化斜率重复的线性核，改用归一化循环数上的Matérn-3/2核；区分潜在轨迹区间和未来实测区间，后者补加观测噪声。
6. GP超参数首轮全局共享；参数自助以整块电池重采样并重拟合完整流程；EOL首次通过时间只作用于无测量噪声潜在轨迹，删失超过50%时不报告有限中位数。
7. 验证场景合并为已知策略留一电池和整组留一策略；所有处理嵌套在外层训练集。
8. Elastic Net改为行组稀疏的多任务惩罚；预测相对SOH轨迹以保证第h循环连续；每个观察长度单独训练。
9. 连续优化只调用模型二的总体退化代理，不调用需要早期个体数据的GP；平均轨迹显式积分对数正态随机斜率。
10. 风险目标改为自助分位数，区分均值不确定性与新电池预测分位数，不再声称搜索域同时置信上界。
11. 新旧结构分别构造几何插值域；新结构6点凸包只作探索性插值，旧结构2点只能沿线段；同时约束决策空间和代理特征空间距离。
12. 增强切比雪夫改用不裁剪的正仿射尺度，并补充可行域紧、目标连续的存在性条件。正式推荐以已观测策略离散Pareto前沿为主，连续结果只称待实验候选。

## 未照搬的建议

- 未完全取消连续优化模块，因为题目4明确要求提出新的充电策略；但严格降级为通过留一策略基线比较后才展示的探索性候选，并要求新实验验证。
- 未把GP用于远期寿命主结果；保留其作为151—200循环主预测候选和EOL敏感性工具，远期主外推由单调参数模型承担。

## 复核后的边界

可验证：0—200循环策略差异、第151—200循环预测误差与覆盖率。不可验证：真实80% SOH寿命精度、连续新策略真实性能和域外安全性。
