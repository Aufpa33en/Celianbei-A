# Q2 T80 全流水线 bootstrap

## 范围

修复旧 bootstrap 只对已经算好的 T80 重采样、未传播寿命窗口选择与 T80 重估误差的问题。论文主文不修改；只更新代码、正式 CSV、技术结论、论文素材图和日志。

## 算法

每次重复在9种策略内按原样本量有放回抽取整块电池，然后：

1. 用抽到且具有200循环的电池重新比较30/40/50/60/80循环尾窗；
2. 用新窗口对所有抽样电池重新计算T80；
3. 聚合6个明确新结构策略的`mean(log(T80))`；
4. 重新做留一策略坐标验证并在J、H、三个高SOC暴露量及常数模型中选择；
5. 保存逐次模型、改善率、斜率、LOCO RMSE和窗口。

## 等价实现与性能

- 可信基线：逐次复制循环DataFrame并调用原Q1窗口/T80函数。
- 正式后端：预计算每块电池×每个窗口的近端RMSE与T80，重采样时只重组充分统计量；算法、样本计划和决策规则不变。
- 3次重复逐行等价检查：决策不一致数0，最大数值差异小于`1e-10`。
- 基线10次墙钟约`2.64 s`；缓存100次墙钟约`2.70 s`（含数据加载和预计算），避免直接运行约10倍重复开销。
- 正式2000次缓存运行`34.81 s`，固定种子`20260816`，样本计划共98000行。

## 正式结果

- `linear_J`入选频率：`77.55%`。
- 相对常数模型LOCO RMSE改善中位数：`20.46%`。
- 改善95%分位范围：`[-10.29%, 47.86%]`，跨0。
- 尾窗重选：40循环`1991/2000=99.55%`，30循环`9/2000=0.45%`；其余窗口0次。
- 固定T80旧bootstrap的`linear_J`入选率为`77.70%`、改善区间`[-10.68%,49.34%]`。全流水线传播后结论没有反转，但主区间略有变化。
- 删除3.7C→5.9C极端策略后仍只剩常数模型；确认性参数效应依然不成立。
